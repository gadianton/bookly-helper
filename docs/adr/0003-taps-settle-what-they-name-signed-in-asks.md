# 0003: Taps settle what they name; only a signed-in shopper's order and return taps ask which one

2026-10-17. Everything in 0002 still holds, except that its rule "a kind-of-help tap always asks which order or book" now covers only a signed-in shopper's order-status and return taps: the "Reset my password" tap goes straight to the reset, and a signed-out visitor's order-status and return taps get the fixed sign-in reply.
